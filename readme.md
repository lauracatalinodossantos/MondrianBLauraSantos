# Mondrian B

Para o elemento que destabiliza a composição, optei por uma oscilação da linha central do quadro. Utilizei o random, e defini os parâmetros de forma a que linha fique sempre ligeiramente torta de forma aleatória. Ou seja, o limite de baixo da linha fica ligeiramente para a esquerda ou direita, e o mesmo se aplica para cima. Deste modo, consegui criar uma oscilção que não quebra a geometria do quadro de forma abrupta, mas cumpre o critério da destabilização.
